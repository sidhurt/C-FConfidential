# Instructions for AI Agents

Read `AI_OPERATING_RULES.md` first, then `PROJECT_BRAIN.md`, `PROJECT_CONTEXT.md`, `ARCHITECTURE.md`, `ROLE_BOUNDARIES.md`, and `MASTER_PLAN.md`.

Your first response to a new source or assignment must:

1. summarize what is newly verified;
2. classify evidence and contradictions;
3. identify affected registers;
4. list the highest-impact missing decisions;
5. propose a bounded next plan.

Do not act on SAP or other enterprise systems. Plans and drafts only until explicit, target-specific approval.

Never infer frontend ownership. Do not implement UI work.

Use the templates. Maintain IDs consistently. Never overwrite uncertainty.
