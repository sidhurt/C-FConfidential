## Required KT outputs

For each KDS/master code, capture:

- business definition;
- SAP table/field/domain;
- allowed values and descriptions;
- derivation or user input;
- valid combinations;
- owning team;
- process impact;
- API field(s) using it;
- sensitive-data classification;
- evidence and last validation.
